Stage 1 — the whole thing

Everything we have agreed, in one place. Nothing about Modelica appears anywhere in this stage.

Stage 1 does
find real, peer-reviewed papers on a topic
check they exist and are not withdrawn
follow references outward until the search dries up
read the best ones and record what they found
build the citation web and the summaries
let you approve the final list
freeze it so it cannot change later
Stage 1 does not
look for gaps  — stage 2
write hypotheses  — stage 2
know which Modelica models exist  — never
collect parameters for building models  — separate stage
run anything
The run, start to finish
seed
Start from a survey paper if you have one, or from written queries if not. Its reference list is the first batch.
search
OpenAlex and Semantic Scholar, several queries at once.
merge
Join duplicates by DOI, then by title. Already built.
check
Real venue, confirmed twice. Not retracted. Not an editorial. If it looks like a preprint, go find the published version and use that instead.
judge
Match on meaning, not shared words. A cheap model reads the abstract and says keep or drop, with a reason.
follow
From the papers that were kept, pull what they cite and who cites them. Back to merge.
stop?
If a whole round mostly returned papers we already had, stop. Otherwise go again on the part that looks thin.
read
The best ~20. Full PDF where the licence allows it, abstract otherwise. Record which one it was for every single fact.
organise
Citation web, the findings as linked facts, and grouped summaries so it fits in context later.
approve
You see the list, add or remove papers. What you change is recorded — that is the answer key the system learns from.
freeze
Locked list with a fingerprint. Stage 2 can only ever see this.
What comes out
Core pile — ~20 papers, read properly, findings recorded with the sentence they came from
Wide pile — a few hundred, title and abstract only
Citation web — who cites whom, exact
Summaries — grouped, so a wide question does not need 300 papers
A record of the run — queries tried, what was dropped and why, what you changed
An honest limit

We can only download a paper when its licence clearly allows it. Your acquire.py is strict about this on purpose, and that is the right call.

So some of the best papers will only ever be read as an abstract. Every fact records which it was, so nobody can later mistake a guess from an abstract for something read on page 7.
