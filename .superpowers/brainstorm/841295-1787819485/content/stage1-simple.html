Stage 1 — Find research gaps

Papers go in. A short list of good, checked gaps comes out. Nothing about Modelica models here.

The four steps
1. Read
Lock the set of papers so it can't change halfway through.
→
2. Guess
The AI writes a first batch of possible gaps.
→
3. Improve  ↻
Keep changing and re-scoring the gaps. This is the loop.
→
4. You approve
You see the final list and accept or send it back.
Inside step 3, over and over
Pick
the most promising gap so far
→
Change it
make it narrower, wider, split it,
or go read more to back it up
→
Score it
see the rules below
Good gaps get picked again and improved further. Bad ones get dropped.
You can stop it at any point and start again from where it left off.
How a gap is scored
Thrown out  —  it made up a source
Thrown out  —  someone already did this work
Loses points  —  too vague to test
Loses points  —  nearly the same as another gap
Gains points  —  real papers back it up
Gains points  —  it is specific and interesting
The important one

“Someone already did this” is checked by a second AI whose only job is to prove the gap wrong.

It searches your papers, then searches the internet, trying to find work that already fills the gap.

If it finds one, the gap is dead. This stops the system from just inventing gaps that sound good.

About Modelica models. Right now the code only lets the AI find gaps it already owns a model for. We delete that. Each gap instead just writes a plain sentence saying what kind of simulation it would need. Nobody checks it. That sentence becomes the to-do list for building models later.
